📊 Google Sheets 연동 가이드

한양전공(주) 법정의무교육 전자서명 시스템

이 가이드를 따라하면 직원이 서명할 때마다 구글 스프레드시트에 자동으로 기록이 쌓입니다. 최초 1회만 설정하면 됩니다. 약 5분 소요됩니다.

1단계 — 스프레드시트 만들기

1 sheets.google.com에 접속해 빈 스프레드시트를 새로 만듭니다.

2 시트 이름을 한양전공_교육서명기록 등으로 변경합니다.

2단계 — Apps Script 코드 붙여넣기

1 상단 메뉴에서 확장 프로그램 → Apps Script를 클릭합니다.

2 기본 코드를 모두 지우고 아래 코드를 전체 복사 → 붙여넣기합니다.

/**
 * 한양전공(주) 법정의무교육 전자서명 수신 스크립트
 * - POST 요청 시: '서명기록' 시트에 한 줄 추가
 * - 서명 이미지: '서명이미지' 시트에 별도 저장
 */
const HEADER = ['일시','교육명','부서','직급','이름','서명이미지(미리보기)','단말정보'];

function doPost(e) {
  try {
    const ss = SpreadsheetApp.getActiveSpreadsheet();
    let sheet = ss.getSheetByName('서명기록');
    if (!sheet) {
      sheet = ss.insertSheet('서명기록');
      sheet.appendRow(HEADER);
      sheet.getRange('A1:G1').setFontWeight('bold').setBackground('#1f6b3a').setFontColor('#fff');
      sheet.setFrozenRows(1);
      sheet.setColumnWidth(1, 150);
      sheet.setColumnWidth(2, 200);
      sheet.setColumnWidth(6, 220);
    }
    const data = JSON.parse(e.postData.contents);

    // 서명 이미지를 Drive에 저장하고 IMAGE 함수로 시트에 표시
    let imageFormula = '';
    if (data.img && data.img.startsWith('data:image/')) {
      const blob = Utilities.newBlob(
        Utilities.base64Decode(data.img.split(',')[1]),
        'image/png',
        `${data.dept}_${data.name}_${new Date().getTime()}.png`
      );
      // 같은 폴더에 이미지 저장
      const folder = getOrCreateFolder_('한양전공_서명이미지');
      const file = folder.createFile(blob);
      file.setSharing(DriveApp.Access.ANYONE_WITH_LINK, DriveApp.Permission.VIEW);
      const id = file.getId();
      imageFormula = `=IMAGE("https://drive.google.com/uc?export=view&id=${id}", 4, 30, 90)`;
    }

    const row = [
      data.atStr || new Date().toLocaleString('ko-KR'),
      data.trainingName || '',
      data.dept || '',
      data.rank || '',
      data.name || '',
      '',
      data.userAgent || ''
    ];
    sheet.appendRow(row);
    if (imageFormula) {
      const lastRow = sheet.getLastRow();
      sheet.getRange(lastRow, 6).setFormula(imageFormula);
      sheet.setRowHeight(lastRow, 50);
    }

    return ContentService
      .createTextOutput(JSON.stringify({ ok: true, row: sheet.getLastRow() }))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService
      .createTextOutput(JSON.stringify({ ok: false, error: err.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}

function doGet(e) {
  return ContentService
    .createTextOutput('한양전공(주) 전자서명 수신 API 정상 작동')
    .setMimeType(ContentService.MimeType.TEXT);
}

function getOrCreateFolder_(name) {
  const it = DriveApp.getFoldersByName(name);
  if (it.hasNext()) return it.next();
  return DriveApp.createFolder(name);
}

3단계 — 웹앱으로 배포

1 우측 상단 배포 → 새 배포 클릭

2 유형 선택 옆 ⚙ 톱니바퀴 → 웹 앱 선택

3 다음과 같이 설정:

  • 설명: 한양전공 전자서명 v1
  • 다음 사용자로 실행: 나
  • 액세스 권한이 있는 사용자: 모든 사용자

4 배포 클릭 → 권한 승인 요청이 나오면 액세스 승인 → 본인 계정 선택 → 고급 → "(안전하지 않음) 이동" → 허용

5 표시된 웹 앱 URL을 복사해 둡니다. (https://script.google.com/macros/s/...../exec 형태)

⚠ "안전하지 않음" 경고가 뜨는 이유 구글에서 검증하지 않은 본인 작성 스크립트이기 때문이며, 본인 회사 시트에만 쓰는 코드이므로 안전합니다. "고급 → 이동 → 허용"으로 진행하시면 됩니다.

4단계 — 서명 시스템에 URL 등록

1 한양전공_교육서명시스템.html을 엽니다.

2 우측 상단 관리자 버튼 클릭 → 비밀번호 123456 입력

3 상단 📊 Google Sheets 연동 카드에 3단계에서 복사한 URL 붙여넣기 → 저장

4 카드가 초록색으로 변하면 연동 완료. 이제 서명할 때마다 시트에 자동 기록됩니다.

5단계 — 확인 및 운영

직원이 한 명 서명한 후 스프레드시트로 돌아가면 서명기록 시트에 한 줄이 추가되고, 서명 이미지가 구글 드라이브 → 한양전공_서명이미지 폴더에 자동 저장됩니다.

이전에 로컬에만 저장된 서명들은 관리자 메뉴 🔄 전체 동기화 버튼으로 일괄 전송할 수 있습니다.

💡 운영 팁 여러 부서/지점이 같은 시트로 동시에 기록할 수 있습니다. URL만 공유하면 모든 단말의 서명이 한 시트에 모입니다. 단말이 인터넷이 안 되는 환경이면 로컬에 저장됐다가 다음 접속 시 전체 동기화로 올리세요.
🔒 보안 안내 관리자 비밀번호 123456은 HTML 소스를 보면 노출됩니다. 외부 공유 환경이라면 HTML 파일을 열어 const ADMIN_PW = '123456'; 부분의 값을 변경해 주세요.

문제 해결

  • 서명해도 시트에 안 들어와요 — 관리자 화면에서 URL이 저장됐는지, https://script.google.com/macros/.../exec 으로 끝나는지 확인. 끝이 /dev가 아닌 /exec여야 합니다.
  • 이미지가 #REF! 로 표시돼요 — 시트 셀에서 셀 우클릭 → 이미지 → IMAGE 함수 새로고침 또는 페이지 새로고침.
  • 스크립트 수정 후 적용이 안 됨 — 배포 → 배포 관리 → 연필(편집) 아이콘 → 버전 "새 버전" → 배포.
